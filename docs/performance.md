# 桌面端资源与响应优化

Windows、macOS、Linux 共用运行逻辑；没有更改登录身份、云信连接、录制规则、消息数据格式或后台节流设置。

- Windows/macOS 的托盘自定义菜单在首次右键时创建，关闭后闲置 30 秒释放页面，再次右键可重新打开。Linux 继续使用系统原生托盘菜单。
- 桌面端启动时只加载拼音运行库，实际播放视频、直播或上麦时共享加载播放器运行库。加载失败可重试；页面切换后丢弃过期的播放请求。网页沿用其原有按需加载方式。
- 索引与检索通过 Node.js 后台线程执行。主进程保留文件变化监听，首次需要索引时才启动线程；读写在同一线程中顺序执行，退出时等待数据库关闭。索引格式、查询条件、上下文与统计算法保持一致。
- 数据库页面离开后闲置两分钟释放 React 界面，返回时恢复持久化筛选和滚动位置。仍打开弹窗或播放媒体时保留界面。共享资料缓存继续工作。

这是一次短时基线检查，不代表登录后、视频播放、录制或真实历史库操作的占用，也不能代表 macOS/Linux 的内存数值。

实际 Electron 窗口检查覆盖数据库卸载/重挂载、筛选和滚动恢复、弹窗保护、播放器并发加载去重及本地 MP4 播放。检索线程另检查索引完整性、上下文、文件变化、错误恢复和退出；三端安装包验证脚本在原生构建环境中执行打包后的线程检查。Mac/Linux 尚未在当前 Windows 环境实际构建。

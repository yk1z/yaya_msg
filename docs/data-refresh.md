# 基础资料自动更新

桌面端、网页构建及独立数据库页面通过 `src/renderer/data-sync.js` 共享资料缓存。此功能更新成员资料和页面配置，不安装或替换软件程序。

## 发布与检查

`yaya_data` 仓库的 Cloudflare Pages 构建命令为 `node _build/build-data-version.cjs`。脚本为根目录 JSON 和 `profile-photos/index.json` 计算 SHA-256，自动生成 `https://data.gnz.hk/data-version.json`。生成文件不提交回 Git。

客户端首次使用某项资料时加载它，并记录清单中的文件版本。多个页面读取同一地址时复用缓存及正在进行的请求。

- 每 3 分钟检查一次小版本清单。
- 返回窗口、恢复联网、页面显示或切换视图时也会检查，共用至少 30 秒的检查间隔。
- 页面隐藏或断网时暂停后台检查。
- 只有已使用或订阅的文件版本变化时才重新下载该文件；JSON 内容相同时不重复通知页面。
- 清单或资料下载失败时保留已有数据，下次检查再试。

当前覆盖成员资料、总选、公演、发行作品、首页配置、B 站房间配置、公告、歌词索引和历史公式照索引。成员资料继续保留原有本地缓存和历史房间号；更新会同步全局成员检索及已打开的成员档案，保留当前筛选。

旧版客户端继续读取原 JSON，不会自动获得此客户端功能。网站需部署新的前端构建后生效。

## 历史公式照

`scripts/build-profile-photo-history.py` 从公式照下载清单准备图片和索引，按内容哈希去重，并输出同名成员名单。历史图片按年月倒序显示，日期格式为 `2026.09`。同名成员按分团区分；普通转团成员可保留跨分团历史。

更新图片时需要同时重新生成并发布 `profile-photos/index.json`。图片使用内容生成的固定文件名，未变化的图片可以复用。

## 验证

`node --test test/data-sync.test.cjs test/message-room-filter.test.cjs` 验证版本检查、请求合并、失败恢复、隐藏暂停及旧房间号兼容。独立 Electron 检查还覆盖全局检索、已打开档案和历史照片的更新，以及筛选与弹窗保留。
